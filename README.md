# K&S Pulpwerk · 小老鼠造纸坊

Kirkland & Sunshine 的内页排版器。K&S Coverwerk 的姊妹站。
纯前端，单文件，无后端，无构建步骤。

## 功能

- 开本：A5 / B5 / A6 / B6（ISO 216）
- 横排（左翻）与竖排（右翻），同一套分页器
- 自动分页：按行拆段，章题不落页尾，8 万字约 1 秒
- 版心按字格对齐：每行 N 字 × 每页 M 行
- 章节：`#` / `##` 标记，或自动识别“第X章”
- 自动目录，页码回填
- 页眉（双数页书名 · 单数页章名）、页码（四种位置）
- 扉页、献词页、版权页（奥付）
- 整页插图：满版或留白，不打断正文
- 粗体、着重号、注音（ruby）、场景分隔、强制换页
- 竖排：“”转「」，数字纵中横，西文自动侧转
- 总页数自动补齐到 4 或 2 的倍数
- 导出：浏览器打印为 PDF，矢量文字，字体内嵌，纸张尺寸自动设定
- 稿件与设置自动存在本机浏览器
- “去做封面”按钮把页数、开本、装订方向带到 Coverwerk，自动算书脊

## 标记语法

| 写法 | 效果 |
|---|---|
| `# 标题` | 章标题 |
| `## 标题` | 节标题 |
| `---` | 场景分隔 |
| `===` | 强制换页 |
| `**文字**` | 粗体 |
| `^^文字^^` | 着重号 |
| `{汉字|注音}` | 注音 |
| `[图1]`（独占一行） | 整页插图 |

## 导出设置

打印窗口里：目标选“另存为 PDF”，边距选“无”，勾选“背景图形”。
建议用 Chrome 或 Edge。

## 部署到 GitHub Pages

1. 新建公开仓库 `ks-pulpwerk`。
2. 上传 `index.html` 和 `README.md`。文件名必须正好是 `index.html`。
3. Settings → Pages → Branch 选 `main` / `/ (root)` → Save。
4. 地址：`https://<用户名>.github.io/ks-pulpwerk/`

## 示例文本

默认示例为陈独秀《敬告青年》（1915 年，《青年雜誌》第一卷第一號）。作者 1942 年去世，文本已进入公有领域。录自维基文库，保留繁体原貌。

## 已知限制

- 插图不随稿件保存，刷新后需重新上传
- 注音和着重号会让所在行略微变高，该页可能少排一行
- Safari / Firefox 的竖排细节不如 Chrome 稳
- 字体经 Google Fonts 加载，首次打开长稿需等字体下载完
